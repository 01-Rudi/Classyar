# جلسهٔ ۱ — معرفی پروژهٔ کلاس‌یار

## فایل‌ها
- `session-01.md` — اسلایدهای Marp (منبع اصلی)
- `session-01.pdf` — خروجی PDF (پس از export بسازید)

## نحوهٔ استفاده

### ۱. با VS Code
1. افزونهٔ **Marp for VS Code** را نصب کنید.
2. فایل `session-01.md` را باز کنید.
3. `Ctrl + K V` (در مک `Cmd + K V`) برای پیش‌نمایش.
4. برای خروجی: Command Palette → `Marp: Export Slide Deck` → PDF.

### ۲. با مرورگر
1. به [web.marp.app](https://web.marp.app) بروید.
2. محتوای `session-01.md` را پیست کنید و PDF بگیرید.
