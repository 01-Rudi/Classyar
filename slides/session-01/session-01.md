# شب امتحان، ده گروه، یک جزوه

---

# مشکل فعلی

- جزوه و نمونه‌سؤال در گروه‌های پیام‌رسان پخش است
- نمی‌شود بر پایهٔ استاد و واحد دانشگاهی جست‌وجو کرد
- کیفیت جزوه معلوم نیست
- دربارهٔ استاد اطلاعات مطمئنی نیست
- دانشجوی دارای جزوهٔ کامل انگیزه‌ای برای اشتراک ندارد

# چشم‌انداز کلاس‌یار

## همه‌چیز بر پایهٔ «استاد + درس + واحد دانشگاهی»

دانشجو پیدا می‌کند → امتیاز می‌بیند → دانلود می‌کند  
استاد تأیید می‌کند → مشارکت‌کننده تشویق می‌شود

|--------|------|-----------|

| امیرحسین | دانشجوی مشارکت‌کننده | دیده‌شدن و بازخورد |
| دکتر کاظمی | استاد | تأیید جزوه و تشویق دانشجویان |
| خانم نوروزی | مدیر سامانه | کنترل محتوا و اطلاعات پایه |

---

# محدودهٔ MVP

**داخل محدوده:**
- ثبت‌نام و ورود با نقش
- آپلود جزوه با استاد، درس، استان، واحد و ترم
- جست‌وجو و فیلتر، دانلود
- امتیاز و نظر به جزوه و استاد
- صفحهٔ استاد، لینک گروه و نمونه‌سؤال
- تأیید استاد و نمرهٔ تشویقی
- گزارش محتوا و پنل مدیر

---

# خارج از محدوده

- ثبت نمرهٔ رسمی در سامانهٔ دانشگاه
- اپلیکیشن موبایل
- چت زنده
- فروش جزوه و پرداخت
- تشخیص خودکار کپی‌رایت و OCR

**دلیل: یک ترم، تیم ۳-۵ نفره، بودجهٔ صفر**

---

# فناوری پیشنهادی

- **Backend:** Node.js + Express
- **Frontend:** React
- **DB:** PostgreSQL + Prisma
- **ابزار:** Git، GitHub Projects، GitHub Actions

**دلیل:** یک زبان برای کل تیم، ابزار رایگان، پایگاه دادهٔ رابطه‌ای برای ارتباط استاد، درس و جزوه
