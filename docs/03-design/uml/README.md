# UML Diagrams — کلاس‌یار

این پوشه دیاگرام‌های UML پروژهٔ کلاس‌یار است. ساختار آن از مدل **4+1 View** گرفته شده:
Use Case در مرکز و چهار نمای دیگر (منطقی، فرایند، استقرار، فیزیکی) دورش.

## فایل‌ها

| فایل | توضیح | وضعیت |
|------|-------|--------|
| `use-case.md` | Use Case Diagram — چه کسی با سیستم چه کاری می‌کند | آماده |
| `use-case-specification.md` | مشخصات Use Caseهای مهم (Flow، پیش‌شرط، جایگزین) | آماده (۷ مورد) |
| `class-diagram.md` | Class Diagram — نمای منطقی | به‌زودی |
| `sequence-diagram.md` | Sequence Diagram — نمای فرایند | به‌زودی |

## ابزار

دیاگرام‌ها با **Mermaid** داخل Markdown نوشته می‌شوند، تا در GitHub مستقیم نمایش داده شوند
و با کد در مخزن نسخه‌بندی شوند.
