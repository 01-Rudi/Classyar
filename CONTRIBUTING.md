# Contributing

## Branch Strategy
- `main` — stable
- `feature/*` — new features
- `docs/*` — documentation
- `fix/*` — bug fixes

## Commit Format
`type: subject`

Types: feat, fix, docs, style, refactor, test, chore

Examples:
- `docs: add personas document`
- `feat: add note upload form`
- `chore: add base project files`

## Pull Requests
- هیچ‌کس مستقیم روی `main` کامیت نمی‌کند؛ هر تغییر با Pull Request وارد می‌شود.
- هر PR حداقل یک تأیید (Review) از عضو دیگر تیم نیاز دارد.
- در توضیح PR شمارهٔ Issue را بنویسید (مثلاً `Closes #12`).
- CHANGELOG در پایان هر Sprint به‌روز می‌شود.
